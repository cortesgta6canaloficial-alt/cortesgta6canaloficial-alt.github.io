# Privacy Policy — Cortes GTA6 Studio

Last updated: November 18, 2026

Cortes GTA6 Studio is a private, single-user tool operated by the owner of the "Cortes GTA6" channel.

## Data we access
- **TikTok:** basic profile information (user.info.basic) and permission to upload videos as drafts (video.upload) to the owner's own TikTok account.
- **YouTube:** permission to upload videos to the owner's own YouTube channel, through YouTube API Services, and public data about public videos and live streams.
- **Twitch:** public information about public live streams and clips.

## How we use it
Data is used only to upload the owner's edited videos and to find public gaming content. We do not sell, share or transfer any data to third parties. We do not collect data from other users.

## Storage and retention
Access tokens are stored only on the owner's local computer and are deleted when access is revoked.

## YouTube API Services
This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms). See the Google Privacy Policy: https://policies.google.com/privacy. You can revoke access at any time at https://myaccount.google.com/permissions.

## TikTok
You can revoke access at any time in the TikTok app: Settings and privacy > Security > Apps and services permissions.
